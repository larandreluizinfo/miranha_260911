# AGENTS

## Regra obrigatória de versionamento

- Toda alteração feita neste repositório DEVE ser commitada e enviada (push) para o GitHub.
- Nunca deixe alterações apenas locais: após editar/criar/remover arquivos, execute `git add`, `git commit` e `git push`.
- Use mensagens de commit claras em português.
- Não acumule várias tarefas sem commitar: commite e pushe ao final de cada alteração ou tarefa.
- Antes de finalizar qualquer resposta de trabalho, confira com `git status` se não restou nada sem commitar/pushear.
